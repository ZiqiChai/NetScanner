# 使用指南

[返回首页](../README.md) · [安装与部署](INSTALL.md)

## 界面与首次扫描

![NetScanner 主窗口](ui-preview.png)

左侧为扫描配置，右侧为结果工作区。首次启动目标是 `127.0.0.1`，默认端口为 `22,80,443,445,3389,8080`。程序不会自动扫描网卡所在网段。

1. 选择“IP扫描”或“端口扫描”。
2. 从“本机网段”选择一项，或在目标输入框填写地址/范围。
3. 填写 TCP 端口；两种模式都使用这里的端口进行探测。
4. 点击“开始扫描”，右侧持续更新结果；需要中断时点击“停止”。

扫描中目标和高级参数被锁定。停止会保留已完成结果，尚未确认的主机显示“已取消 / 未确认”；再次开始会清除当前结果并执行新任务。扫描结束后，异步主机名查询仍可能稍后更新名称。

## 输入格式

支持以下 IPv4 输入，可以用逗号、分号或空白组合；重复分隔允许，重复目标自动去重：

```text
192.168.1.10
192.168.1.0/24
192.168.1.10-192.168.1.30
192.168.1.10,192.168.2.0/28
```

IPv4 必须写完整四段规范十进制。`010.0.0.1`、`127.1`、十六进制地址、带 `+` 号的数字均拒绝，以避免误扫其他地址。CIDR 小于 `/31` 时排除网络地址与广播地址，`/31` 保留两个地址，`/32` 保留单地址。单次最多 4096 个主机。

端口支持列表和升序范围：

```text
22,80,443
1-1024
22;80;8000-8100
```

端口范围为 `1–65535`，拒绝前导零、正负号、倒序范围；重复端口去重。主机数乘以端口数最多 **200000 次探测**，超出时需缩小范围。

## 扫描模式与高级参数

**IP扫描**以 TCP 成功连接或明确拒绝连接判断主机有响应，只保留开放端口子项。**端口扫描**使用相同探测方式，但保留所有已完成端口的结果，适合逐端口检查或导出完整端口记录。

“高级参数”默认折叠：连接超时默认 **600 ms**（100–10000 ms），并发连接默认 **128**（1–512）。网络延迟或丢包较高时可增加超时；并发越高，网络与本机负载越大。每个端口只探测一次，不重试。

## 结果如何解释

主机默认按 IPv4 数值排序，端口按数值排序，例如 `.2` 在 `.10` 前。点击列标题可以切换排序；扫描期间暂时关闭排序更新，结束后恢复。

- **在线**：至少一次 TCP 连接成功或收到端口关闭响应。
- **未响应 / 未确认**：所选端口均未提供成功或拒绝连接响应；不能认定主机离线。
- **开放**：TCP 连接建立成功。
- **关闭**：对方明确拒绝连接；端口未开放，但主机有响应。
- **超时**：连接在指定时间内未得到确定结果，可能受防火墙、丢包等影响。
- **连接错误**：其他连接错误，不计为主机在线证据。

“响应耗时”是 TCP 探测耗时，不是 ICMP ping RTT。主机行显示最近一次有响应的探测耗时，端口行显示该次连接耗时。

主机名来自异步 DNS 查询；MAC 仅来自本机 `/proc/net/arp` 中完整的实际记录，跨网段或沙箱内可能为空。“服务（推测）”基于常见端口名称，不识别实际协议、版本或厂商。主机行该列留空，展开后查看端口行。

## 搜索、隐藏与详情

“隐藏无响应主机”默认启用，只显示已有 TCP 成功或关闭响应的主机。扫描刚开始结果为空是正常现象；取消勾选可以查看全部目标。

搜索同时匹配主机及端口各列内容，不区分大小写。例如可输入 IP、主机名、端口或服务名称。搜索与隐藏条件共同生效，仅改变显示，不改变扫描范围，也不裁剪 CSV 导出。

使用“展开 / 收起”查看端口子项。选择一条结果后，下方显示设备、主机名、MAC、状态、端口/服务与耗时。

## 双击打开服务

仅对**已开放**且具有映射的端口调用系统默认应用：

- HTTP：80、8000、8080、8888。
- HTTPS：443、8443。
- FTP：21。

生成的链接使用扫描结果 IP 和实际端口。端口到协议的映射只是惯例，非标准部署可能不匹配。主机行双击用于展开/收起，关闭、超时和其他服务端口不会自动打开；SSH、RDP 等目前没有双击启动映射。系统未配置相应协议的默认应用时，界面提示打开失败。

## 收藏与设置迁移

“收藏当前配置”保存目标、端口和扫描模式；从收藏下拉框选择后恢复这三项。连接超时、并发和筛选条件不在收藏中。当前不提供收藏删除界面。

设置使用 Qt `QSettings`，组织名和应用名均为 `NetScanner`。Ubuntu 默认原生设置位置为 `~/.config/NetScanner/NetScanner.conf`（受 `XDG_CONFIG_HOME` 影响）。旧版 `LanScanner` / `LAN Scanner` 的 `favorites` 仅在新设置中尚无该键时迁移；已有收藏及明确保存的空列表均保留，不覆盖。迁移不删除旧配置。Flatpak 版本使用沙箱内独立的配置目录。

## 导出 CSV

点击“导出 CSV”，选择保存位置。输出字段为 `IP,Port,Status,Service,Latency,Progress,Hostname,MAC`，包含主机行及已生成端口子行，使用带引号字段处理逗号、引号和换行，并对可能被电子表格解释为公式的开头进行转义。

**导出全量已生成记录，不只导出当前可见行。** 隐藏和搜索不会裁剪导出内容。扫描进行中或停止后导出的是当时已有结果，不代表所有探测完成；IP 模式未生成的关闭/超时端口不会出现在 CSV 中。需要完整逐端口记录，请选端口扫描并等待完成。文件通过原子写入保存，写入失败时弹出错误提示。

## 与 Nmap 的区别

NetScanner 的探测方式对应 `nmap -sT -Pn`（TCP Connect，跳过主机发现）。Nmap 默认的 ICMP / ARP 主机发现与 SYN 扫描是不同的方法，结果可能不同。与 Nmap 对比时，请使用相同的目标、端口和扫描方式。

不支持 IPv6、UDP、SYN 扫描、操作系统识别与服务版本探测。
